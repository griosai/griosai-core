# Code Of Conduct

GriosAI uses a simple contributor covenant: be respectful, be precise, and keep
people's private data out of public project spaces.

## Expected Behavior

- Use welcoming and direct language.
- Assume good intent while staying factual about technical risk.
- Keep issue and pull request discussion focused on reproducible behavior,
  privacy boundaries, tests, and documentation.
- Redact credentials, vault contents, screenshots, local paths, and raw logs.
- Respect maintainer decisions about delaying or declining work that changes
  local-first defaults, public exposure, or data-export behavior.

## Unacceptable Behavior

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing another person's private data, credentials, screenshots, notes, or
  local filesystem paths.
- Pressuring maintainers to disclose security issues before a fix is available.
- Repeatedly reopening decisions without new evidence.

## Enforcement

Maintainers may edit, hide, or remove comments that expose private data or
violate this code. They may also lock discussions, close issues, or block
contributors who continue harmful behavior after a warning.

Report conduct issues privately through the maintainer contact path in
[GOVERNANCE.md](GOVERNANCE.md). Report vulnerabilities through
[SECURITY.md](SECURITY.md).
